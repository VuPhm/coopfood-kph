# Store App contract index

Index này dẫn tới nguồn authority và test, không thay thế contract đã accepted.
OpenAPI chung nằm tại [`contracts/openapi/kph.openapi.yaml`](../../contracts/openapi/kph.openapi.yaml);
fixture tổng hợp và golden case nằm tại [`contracts/fixtures`](../../contracts/fixtures).
Code đang chạy là bằng chứng implementation, không tự trở thành contract mới.
