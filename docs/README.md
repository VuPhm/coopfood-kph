# Tài liệu dự án

Thứ tự đọc bắt buộc cho mọi thay đổi:

1. `CURRENT_STATE.md`
2. `NEXT.md`
3. `ENGINEERING_PRINCIPLES.md`
4. Tài liệu product liên quan trong `product/`
5. ADR đã accepted trong `adr/`

`SOURCE_MANIFEST.md` ghi provenance của tài liệu, fixture và khung giao diện
được mang từ hai repository tham chiếu. Hai repository đó là read-only.
