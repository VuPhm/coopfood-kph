## Query-plan and index decision

The committed SQL copies schema widths/constraints/indexes into temporary tables
and populates **20,000 records / 40,000 photo metadata rows** from synthetic seed.
This is a query-shape experiment, not an HTTP latency or production load test.
Final isolated EXPLAIN ANALYZE timings:

- Old join-all shape: **140.266 ms**, sorts 40,000 joined rows.
- D01 filtered count: **4.463 ms**.
- D01 type totals: **5.646 ms**.
- D01 record-first page + ordered photos: **0.563 ms**, record limit 25 before fan-out.
- Sequential D01 query sum: **10.672 ms** in this single local measurement.

Existing indexes suffice for the measured default order. No new index or migration;
deep offsets, production capacity and all possible text-sort loads are not proven
by this sample. PostgreSQL `vi-x-icu` support and displayed-label sorting were
exercised by integration tests on the actual PostgreSQL 17 image.
